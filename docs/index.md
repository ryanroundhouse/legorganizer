# Legorganizer

Legorganizer helps you catalog your LEGO parts and remember which storage bin
each one lives in. Search by part number or name, browse by category, snap a
photo to identify an unfamiliar part, and export your collection as JSON.

- Android: [Google Play](https://play.google.com/store/apps/details?id=com.gencorp.legorganizer)
- iOS: App Store (coming soon)
